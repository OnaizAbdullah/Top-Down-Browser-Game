The game is called Orb Collector. You are a bacteria an have to collect a certain amount of orbs to win. 
Avoid being hit the viruses!

Make sure to:
• Place all the HTML files in a folder called templates.
• Place all the .mp3, .ogg, .css, .png, .wav, .js files in a folder called static.
• Place all other files in the same directory as these folders.
• Double check that all the folders and files are in the same directory.
• In the app.py terminal, run the command "python -m flask run" to startup the website.
• Have fun!
